# 초도상담 신입사원 교육

인테리어·리모델링 상담 직무 신입사원을 위한 초도상담 교육 웹 자료입니다. 표지부터 평가 기준까지 12개 내용을 교육 자료와 같은 순서로 읽고, 각 장의 강사 노트를 펼칠 수 있습니다. 원본 프레젠테이션은 페이지에서 바로 받을 수 있습니다.
